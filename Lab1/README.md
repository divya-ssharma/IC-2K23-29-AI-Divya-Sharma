# Lab 1

Name: Divya Sharma  
Roll No: IC-2K23-29

This lab covers three classic state space problems from the first unit: water jug, vacuum cleaner, and missionaries and cannibals.

The water jug problem is implemented as a fill-and-pour loop using a 4 litre jug and a 3 litre jug, with the goal of measuring exactly 2 litres in either jug. The vacuum cleaner is a reflex agent for two rooms, taking the initial status of each room and the vacuum's location as input, and applying simple production rules until both rooms are clean. Missionaries and cannibals is solved with BFS over the set of valid states, since the boat can carry at most two people and the missionaries must never be outnumbered on either bank.

The missionaries and cannibals program prints the complete state path. The other two print each action as it is applied.
