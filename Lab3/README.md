Data preprocessing and exploratory data analysis on a small dataset created for the lab. The dataset has a few missing values in the age and marks columns, and a placed column stored as text.

Missing ages were filled with the mean and missing marks with the median. The placed column was mapped to 1 and 0 so that it can be used as a target later. After cleaning, a summary of the data was printed using describe(), followed by two plots: a histogram of marks and a scatter plot of age against marks.

Since the dataset is small, the summary statistics are not very meaningful, but the same steps would apply to a larger dataset.
